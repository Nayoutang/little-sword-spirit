《Little Sword Spirit》试玩版

运行方式
1. 解压整个压缩包。
2. 双击 LittleSwordSpirit.exe。

联网对话
试玩包已包含测试用 API 配置，正常联网即可使用。请勿转发或公开发布此试玩包。

v1.8 战斗更新
1. 小墨现在是独立的第二牌手。玩家结束回合后，她会先打出一张自己的牌，再进入敌方行动。
2. 她只能从当前羁绊阶段解锁的有限卡池中选牌；LLM 只负责选择卡牌 ID 与给出理由，伤害、格挡和连击均由本地规则结算。
3. 她会参考当前战局、关系阶段、共同胜负与约定记录。网络超时、返回非法卡牌或 JSON 格式错误时，会自动使用本地兜底决策，不会卡住战斗。
4. 系统会记录整趟远征中的每场战斗、生命变化、最高连击、双方出牌、事件选择、奖励和约定结果；回家聊天时，这份记录会作为唯一事实来源交给小墨。
