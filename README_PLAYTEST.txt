《Little Sword Spirit》试玩版

运行方式
1. 解压整个压缩包。
2. 双击 LittleSwordSpirit.exe。

比赛离线版
本版本不需要网络，也不会发起网络请求。小墨战斗使用本地决策；每次远征归来随机出现一次话题，回答后收起，平时不显示闲聊选项。有心事时优先谈心事，暂缓的内容留到下次归来。
飞花令使用本地唐诗三百首、千家诗和剑意诗句，请输入完整一联；标点、空格和繁体字可自动核对。
输入“提示”可查看可用诗句；未收录的诗句不计输赢，可换句再答。
途中对诗可以自选一个汉字或留空随机，家中对诗默认随机抽令字。

v1.8 战斗更新
1. 小墨现在是独立的第二牌手。玩家结束回合后，她会先打出一张自己的牌，再进入敌方行动。
2. 她只能从当前羁绊阶段及对诗领悟解锁的有限卡池中选牌；决策与伤害、格挡和连击均在本地完成。
3. 她会根据战况选择招式，并按关系阶段表达配合意向。
4. 系统会记录整趟远征的共同经历；回家问候会回应真实的胜败、奇遇和约定结果。特殊心事通过选项回应，完成状态保存在原存档中。
