# 大话骰 UI 与美术（2026-10-17）

已将家中骰局改为小墨茶桌对坐界面：左侧人物、台词与小动作，右侧独立显示暗骰、叫数记录、玩家骰子和操作。保持现有大话骰规则、AI 判断、停顿概率和存档结果。

新增背景 `tea_table_v1.png`（1920×1080），生成原稿为 `tea_table_source_v1.png`。工具为内置 imagegen，以既有小墨对白立绘为唯一人物参考。完整提示词、生成 ID、参考、哈希及检查记录见 `asset_manifest.json`。没有新增外部素材。

骰面与骰盅沿用既有 Godot 绘图方式完善，点数仍由游戏数据绘制，避免生成图片出现错误点数。象牙骰面、红色一点/四点、青金骰盅与选中框保持同一色系。既有青金按钮素材复用；加减按钮使用清晰的代码绘制样式。

交互改进：
- 点数按钮显示真实骰面，青色边框表示选中；加减个数与叫数/开骰分区。
- 叫数历史只显示最近四次，鼠标悬停可查看完整记录，长对局不会撑破面板。
- 揭骰时淡入显示，高亮所叫点数和一点；同步显示胜负及双方数量核算。
- 规则弹层阻挡底层输入，有明确关闭按钮；手机返回与 Escape 先关规则，再退出骰局。
- 暗骰阶段不会展示结算数量，角色台词与小动作保持原机制。

验证：`liar_dice_smoke`、`home_ui_smoke`、`mobile_adaptation_smoke` 共 3/3 通过。小游戏检查覆盖完整对局、结果记忆、再来一局、家中入口及返回；新增规则返回、结算显示与提示更新断言。Godot 4.7.2 实机检查了开局、思考、回应、揭骰、规则及 1280×720 窗口。系统证书/默认日志目录写入为环境警告；离线测试使用隔离目录，未见脚本错误。实体手机未验收。
