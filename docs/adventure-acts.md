# 奇遇三幕扩展

五个奇遇各保留首幕，新增相处与收尾两页，共十张新插画。每页三格，按点击逐格显示；读完第二幕后显示原有两条回应，选择后进入第三幕。独立结果纸页在第三幕读完后显示本地结果，小墨回复返回后更新台词并启用继续按钮；网络失败仍使用已锁定的离线回应。

文字、选项、结果、恢复量均为原生 UI。结果页在 ui/adventure/adventure_result.tscn，可独立调位置、字体与纸张，不烘焙入漫画。原有生命上限与羁绊结算、共享经历记忆保留，resolved 阻止重复发奖。玩家主角不展示脸、身体或手，保持性别留白。

新素材位于 art/story/adventures，各事件 *_middle_v2.png 与 *_ending_v2.png。由内置 ImageGen 参考对应 *_v1.png 生成，保留小墨服饰、面容与场景；三格倾斜分镜、彩色手绘风，无文字或 UI。相处页分别为雨亭让出干燥座位、观察剑痕力道、给灯灵认路、试桥板、添柴；收尾页分别为雨渐停、暮色收手、灯灵归位、对岸回望、火边暖水。

tools/adventure_acts_smoke.gd 检查五个事件的两条分支：三幕推进、结果延后出现、恢复不重复、反馈内容一致。--adventure-screenshot 生成实际渲染截图。测试隔离存档，离线运行。
