# 漫画剧情接入

初遇使用 `scenes/intro.tscn`，顺序读取 `art/story/intro/` 的四张最终漫画。首次只显示一格；点击画面或按空格/回车逐格淡入，当前页读完再点击才翻页，最后一页读完进入家中。移除翻页按钮、页码、阅读说明和称呼输入，默认称呼「持剑人」。已有完成初遇的存档继续正常进入家中；新存档会进入漫画初遇。

五种奇遇使用 `scenes/adventure.tscn` 和 `art/story/adventures/` 对应的 `_v1.png`。点击画面逐格阅读，最后一格出现小墨台词，再点击显示两种回应，结算后点击画面继续赶路。图片保持无文字，台词、分支结果及在线生成回应由 UI 展示，避免文字烘焙后与动态结果冲突。

布局在 `ui/shared/comic_reader.tscn`。Page 控制漫画显示区域，Caption 控制叙述区域，Choices 控制选项位置。脚本只改变内容与显隐，不重设这些节点的位置或字号。图片保持比例显示，不裁掉分镜。

分镜边界和顺序在 `ui/shared/comic_panels.json`，坐标相对整张图片归一化到 0–1，可修改倾斜多边形。Page 节点的 `reveal_duration` 控制淡入时长，默认 0.35 秒。淡入中点击仅完成当前格，避免快速点击跳过下一格。翻页后会重新从第一格开始，窗口变化时保留已经揭示的分镜。

初遇 Page 开启 `fill_frame` 并清零四周偏移，整页适配窗口宽高，不裁掉对白；与原图比例不同的窗口会调整横纵比例。小旁白由 `ui/shared/comic_text.json` 配置，引擎文字层覆盖原图小字并随父分镜淡入。输入事件在推进剧情前标记已处理，避免换场景后访问已脱离场景树的视口。

旁白现改为无底框、左对齐的浅米白文字、细暗描边，统一 25 字号，楷体优先（系统缺失时使用宋体/引擎回退）。对话保留原漫画气泡。三张清理后的图存于 `art/story/intro/*_unboxed.png`，保留原图备份；内置 imagegen 编辑提示：仅删除矩形旁白框及其中的字，补回背景，保留构图、分镜边界、颜色、角色、古剑、全部对话气泡与中文对白、拟声字，不添加其他文字或元素。

## 图像生成记录

第二页使用 `intro_comic_02_acquaintance_v2_unboxed.png`：内置 imagegen 局部编辑，删除右页第三格“先叫我持剑人吧”及末格“持剑人？行，倒也好记。”两处完整气泡并补回背景，保持其他对白、分镜和画面。两处都由游戏使用已确认的名字绘制美术气泡；文字近黑色配 1 像素同色描边，以匹配原图墨色。姓名输入框也使用同样墨色。

交互气泡和姓名输入卡使用内置 imagegen，素材存于 `art/ui/comic/bubble_v1.png`、`art/ui/comic/name_card_v1.png`。以第二页漫画为参考：气泡为留白的象牙纸色有机椭圆、细而不规则的墨线和左下指向尾巴，透明背景，无文字与装饰；姓名卡使用同样纸色墨线、上方标题留白、下方长姓名栏及青色确认标签，透明背景，不生成文字。运行时用这些图片贴图替换 StyleBoxFlat，动态名字、输入控件、奇遇对白及旁白共用 `ui/shared/comic_font.tres`，优先楷体。原图中的烘焙对白保留，字体匹配为近似，动态文字始终可编辑。

工具：内置 imagegen。参考：已确认的 `intro_comic_spread_v4.png` 与 `sword_spirit_dialogue_portrait.png`。

五张图共同提示要求：彩色漫画叙事，三块大小不同的倾斜分镜、米白分镜间隙；沿用深青山林、青蓝山石、暖金光线；小墨保持深发、琥珀眼、白花和青金发饰、象牙白与青色服装；古剑为直刃、深色剑柄和青色流苏。不展示玩家的手、身体、袖子或影子；不绘制文字、气泡、按钮。

各图场景提示：

- rain_pavilion：雨中废亭全景，檐下雨滴特写，小墨在干燥长凳边陪伴，剑与剑鞘在旁。
- sword_trace：古老崖壁剑痕，末端颤动特写，小墨认真辨认痕迹。
- lost_lantern：林间迷路暖色灯灵，灯光特写，小墨指出通往山祠的方向。
- broken_bridge：月色残木桥，断裂桥板特写，小墨在安全一侧查看并示意等待。
- old_waystation：暮色旧驿站，炉膛余火特写，小墨在火边看旧墙刻痕，不画可读文字。

验证：`tools/comic_story_smoke.gd` 覆盖四张初遇图、翻页边界、称呼保留、五种奇遇十条分支、离线回应与重复点击不重复结算。`tools/comic_preview.gd` 可生成实际渲染截图至 `.godot/`。
