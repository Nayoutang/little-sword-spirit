# 开发日志01：大模型方案砍掉了，改成离线版

先简单介绍一下我们的游戏。《捡到一只小剑灵》是一款双人卡牌游戏，主角捡到一把古剑，剑里住着剑灵小墨。战斗时你和小墨一起出牌，她会先亮出这回合要出的招，你再决定怎么配合。路上可以和她玩飞花令，对出带剑的诗句她就能学会新的剑招。打完一趟远征回到小屋，可以和她聊天，随着羁绊加深，她能用的招式也会变多，最后会有不同的结局。

我们一开始的想法是用大模型来驱动小墨。战斗时让模型帮她选牌，小屋里可以和她自由聊天，飞花令也是模型来出句和判对错，奇遇结束后她的回应也是现场生成的。为了防止卡住，每次请求设了超时，超时就走本地逻辑。

今天看比赛规则，发现不允许游戏联网。大模型要联网，所以这一套在比赛版里都不能用。

把每个地方断网测了一下：战斗没问题，本地出牌规则本来就能用；奇遇和约定会显示预先写好的台词，也能正常走；飞花令直接开不了局；小屋聊天只会提示服务不可用。飞花令是学剑招的唯一途径，这个坏了影响最大。

接下来的改法：

1. 战斗只用本地出牌规则。
2. 飞花令做一个本地诗库，小墨从诗库里出句，玩家的句子也拿诗库来对。剑诗本来就是本地数据，对上了照样能学剑招。
3. 小屋聊天改成选话题，不再自由输入。
4. 打包时把联网相关的东西全部去掉。

这件事的教训就是比赛规则要第一天就看完，不然很多东西白做了。
