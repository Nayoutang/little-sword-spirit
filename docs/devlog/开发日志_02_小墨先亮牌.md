# 开发日志02：小墨的意向系统

游戏是双人卡牌战斗，你出你的手牌，小墨出她的剑招。

每回合开始的时候，小墨会先把这回合要出的招亮出来，叫意向，亮出来之后就不会再改。比如她亮「剑影回护」，就是要给你挡 6 点伤害，那你这回合就可以放心进攻；她亮「引势」，你下回合第一张攻击牌伤害翻倍，那你可以把重击留到下回合。

这么设计是因为如果她在你出牌之后才行动，你没法配合她，她打得好打得坏都跟你没什么关系。先亮出来，你就可以围绕她的招来安排自己的牌。

她选什么招是一套本地规则决定的：先把明显不合适的牌排除掉，比如你快死了她不会去出一张没用的攻击；剩下的牌按伤害、能不能补刀、能不能接你的连击来打分。另外她会记录你接住了几次她给的配合，接得多的话她会更倾向于给你开配合。

我们讨论过要不要让她在你出牌后临时换招，最后没做，因为亮出来的招如果会变，玩家就没法信任它了。
