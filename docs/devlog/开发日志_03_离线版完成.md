# 开发日志03：离线版改完了

第一篇说到要把游戏改成离线版，现在已经改完了，记录一下具体改了哪些地方。

## 飞花令

原来飞花令靠大模型出句和判断，现在换成了本地诗库。诗句来自开源项目 chinese-poetry，选了唐诗三百首和千家诗两部分，筛出完整的上下两句，统一转成简体，去掉重复的，最后得到 2178 联。

现在小墨从诗库里找含令字的诗句来出，玩家输入的句子也拿诗库去对。8 句剑诗本来就在游戏数据里，玩家对出来照样能学会对应的剑招。

有一个问题是诗库没收录的句子，不能说明是玩家编的，可能只是我们没收。所以遇到没收录的句子，小墨不会判你输，只会说这句诗卷里没有，让你换一句，这一轮不计输赢。实在想不出来可以输入"提示"，她会给一句能用的。

## 小屋聊天

自由输入改成了选话题。每次有两个话题可选，比如"你觉得我出剑怎么样？""陪我坐一会儿吧"，小墨的回答会随羁绊阶段变化，同一个话题在初遇和交心时说的话不一样。

远征回来时她先开口的那一句也保留了，改成用模板来写。之前几个需要通过聊天解决的"心事"事件，也改成了用选项来回应。

## 战斗、奇遇、约定

这几处本来就有本地逻辑，直接用本地的就行。

## 打包

联网的开关在比赛版里固定关掉，命令行参数也打不开，请求地址也清空了。单独配了一个比赛版的导出设置，开发用的工具、实验数据和概念图都不打进包里。

改完以后有个意外的好处：战斗时不用再等网络，小墨出牌快了很多。
