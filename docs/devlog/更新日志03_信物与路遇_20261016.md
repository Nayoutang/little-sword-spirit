# 更新日志03：路上多了些相遇，也多了些信物

昨天带着小墨追了第二章的「线头」，今天想把赶路这件事再填得丰富一点。这次加了信物和路遇，也补了一些小墨的心事对话。

先说信物。这次新增了10件，有旧剑鞘、青色剑穗、半块玉佩，也有同心结和铜铃。打赢精英敌人可以获得，遇到宝箱时，也可以选择取一件信物。

它们会和你们的配合一起起作用。比如小墨亮出「守护」意向时，青色剑穗能让你多抽一张牌；接住她留下的机会时，半块玉佩能回复一些生命。不同信物适合不同的打法，希望每趟历练拿到的东西，都能让接下来的出牌多一点变化。

信物只在当前这趟历练里生效，下一趟会重新收集。中途退出再回来，已经拿到的信物会随进度一起保留。

地图上的问号节点也添了些新内容。路过荒庙，可以上一炷香，也可以不打扰；碰到断桥，可以涉水去捡对岸的包袱，也可以陪小墨绕一段路。还有卖剑穗的老人、受伤的剑客……路上遇到的事，会多给你几个选择。

有些选择会影响生命、卡牌或这趟历练的收获，小墨也会有自己的反应。选牌、移除卡牌这些过程补了中途保存和恢复，方便下次接着走。

回家以后，也补了一些离线心事对话。她救过你、你接住过她留下的机会，或者答应过她的事没能做到，这些经历都会有对应的话可聊。想让一起走过的路，在回家以后也留下一点痕迹。

另外顺手整理了几个入口：「继续旅途」现在会直接进入最近保存的存档；有存档时点「开始游戏」，会打开存档列表，可以继续旧档，也可以选空位开始新旅途。卡牌文字和部分界面展示也做了调整。

本次更新对应安卓 **0.1.6**、PC **3.8.4**，已提交审核，审核通过后会开放下载。第三章还在制作中。

如果遇到信物效果没触发、路遇选项卡住，或者中途退出后进度不对，欢迎留言告诉我。也想听听大家拿到了什么信物，哪一件用起来最顺手，我再接着改。
