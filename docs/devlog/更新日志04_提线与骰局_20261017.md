# 更新日志04：把线斩断，回家摇一局骰子

第三章「提线」这次做完了。

接着第二章留下的线头，你和小墨会走进山谷里的剑冢，再去见那位一直牵着线的人。这一章有两趟历练、两位首领，也补齐了章首、剑冢和终章的插画。前面一起斩过的线、练出来的默契，也会在这里派上用场。具体发生了什么，就留给大家自己走一遍。

这次还加了两页剑谱：「借丝」让斩线后多抽一张牌；「收剑」则试着让你先收住手，由她替你出这一剑。不是每个回合都要抢着把攻击打满，有时候也可以信她一次。

紧张的事做完，回家也添了点消遣。和小墨相识后，家里会出现「骰局」入口，可以陪她玩大话骰。两个人各摇五颗，轮流猜双方一共有几个几点，不信她就开骰。她会接你的叫数，也会吹牛，偶尔还会露出一点小动作。一起玩多了，或许会更懂她。

骰局做了专门的茶桌插画，选点数直接点骰面，开骰后会亮出算进去的骰子，并把你和她各有几颗列出来。规则也改成了更直白的说明：叫的是双方十颗骰子的总数，一点可以当赖子，可不是只数她手里的五颗。

另外修好了家中菜单悬停时报错的问题，整理了一些界面和脚本警告。第三章的六张剧情图、两位首领立绘、两张剑谱图，以及骰局美术都已接入。这次检查了138处美术资源引用，没有缺失文件，52项离线回归全部通过；实体手机还没有做完整流程试玩。

本次对应安卓 0.1.7、PC 3.8.5。两端已提交审核，审核通过后开放下载。
