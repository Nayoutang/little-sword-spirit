# 更新日志05：这一趟，练出你们自己的默契

隔了两天，来补一份更新。这次想解决的是：第三章走完之后，你和小墨还能一起练些什么。

先从战斗里的配合开始。现在这一趟里，你怎样接她的招，她会慢慢记住。常接住她的守护，她会更愿意替你挡；常用好她让出的机会，她会更愿意把出手留给你；替她铺好剑势，她也会更常接过最后一剑。危急时她仍会先看战况，不会为了习惯硬选招式。这份默契每趟重新积累，练出来的样子也可能不同。

围绕这三种配合，补了九张牌：守护这边有「背水、倚剑、托付」，接机会有「顺势、借花、心照」，收尾有「垫步、点睛、剑意相连」。可以试试让她护着你进攻，也可以把机会接稳，或是攒好连击，交给她出最后一剑。三件新信物「旧伞、信笺、断弦」也加入了历练，分别帮这三种打法搭把手。

主线之后的自由历练也加了变化。首领会从已有的几位中随机遇见，普通敌人的搭配也有变化。这次做了五级「剑境」，打通一级再往上走；难度会逐级增加，也会带来更好的选牌、信物等奖励。剑境五打通后，回家还有小墨的一段回应。首领不提前公布，路上见了再拆招。

美术也补了一批：九张新牌都有了独立的水墨插画，十三件信物都有了自己的图标，点开「信物」能一边看物件、一边看它的效果和来历。第三章剑冢的战斗换成了专门的山谷战场，远处是群剑和戏台，眼前留出你们出剑的地方。

这版对应安卓 0.1.8、PC 3.8.6。仍然是离线试玩版，旧存档可以继续使用；如果想试新的构筑，从新一趟历练开始会更方便。实体手机还没有完成全流程试玩。

这次最想听听大家：三种配合里，哪一种打起来最顺手？小墨慢慢接上你的习惯，有没有让这一趟更像是两个人一起打？剑境的难度如果哪里跳得太快，也欢迎带着当时的牌组和截图来告诉我。
