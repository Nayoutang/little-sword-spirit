# 更新日志06：磨一磨剑，也听听她下一招的打算

这次给历练补了一个新选择：磨剑。宝箱里可以选一张牌升级，路上遇到铁匠或无字剑碑时，也能把手里用得顺的招式再磨一磨。41 张牌各有提升，有的伤害更高，有的护得更稳，也有的出手更省精力。升级沿用原插画，牌名后会添上「+」，旧存档可以继续使用。

自由历练线外多了两位对手。「血衣刀客」每回合的攻击都会增加，拖久了就得小心；「墨医」会在普攻和回春之间交替，替血量最低的同伴疗伤。两位都有了独立立绘：一个暗红衣、提弯刀，一个白袍墨染、带药葫芦和金针，见面时更容易认清该先应对谁。

路上也添了六段相遇：路边铁匠、无字剑碑、迷路的孩子、茶摊说书、夜狼和落魄书生。现在共有十五个路遇，打斗之外，可以再停一停，看看这一趟遇到些什么。

家里的大话骰和战斗也接上了一点联系。累计看穿小墨吹牛五次后，她会开始在回合结束时，说出下回合想怎样配合你：替你挡一剑、把机会留给你，或是接过最后一击。她多半会照着自己的打算出手，遇到紧急战况仍会调整。猜得懂骰桌上的她，也许会更容易接住战斗里的下一招。

另外扩写了小墨的离线出牌理由和回家台词。她会根据关系、战况和这一趟的配合，换些说法；回家时，也会提起你们这一路更习惯怎样并肩出剑。

本次对应安卓 0.1.9、PC 3.8.7，仍是离线试玩版，兼容旧存档。54 项离线回归已通过，实体手机尚未完成全流程试玩。两端提交审核后，审核通过即开放更新。

这次也想听听：你最先磨的是哪一张牌？小墨提前说出下一招之后，配合起来有没有更顺手？欢迎带着牌组和截图来反馈。
