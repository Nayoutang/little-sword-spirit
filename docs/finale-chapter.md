# 终章：同归与余途

羁绊满100后，回到家时小墨主动邀约。邀请以她与当前玩家的信任为重心：愿意分享过去，邀请一起面对，而非回归前主人。拒绝进入未归结局；接受在主页保留前往旧祠入口，点击播放回忆、旧祠重逢，然后进行真实终章战斗。胜利进入同归结局，生命归零进入余途结局，小墨以自己最后的剑光击败敌人，玩家带着失去光芒的剑继续生活。

前主人统一参考 former_master_v1.png，银发、破损白瓷面具、灰黑衣袍、古铜剑、幽紫牵引线。告别镜头保持距离，无拥抱或亲密接触。玩家脸、手和性别保持留白。

终章状态由 RunState 唯一持有，保存 finale.state/mode，旧档默认locked。accepted重载保留按钮，story重载回放剧情，battle重载重开终章战斗，ended重载回放对应结局；已结束的存档不能继续普通旅途。新存档和删除重置状态。终章战斗沿用现有首领机制与配合系统，进入前恢复生命；不经过普通地图奖励或约定结算。

素材为内置 ImageGen 参考角色和统一故人生成的彩色漫画，文字独立为原生UI。每页逐格展示，末尾显示旁白。场景在 ui/finale、脚本在 scripts/story/finale.gd 和 scripts/home/finale_invitation.gd。静态漫画呈现，尚未加入配音或专用音效。三种结局由本地分支确定，LLM不能改变终章结果。
