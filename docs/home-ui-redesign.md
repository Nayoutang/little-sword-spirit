# 主界面落地（2026-10-05）

## 分层与微调

- 场景入口：`scenes/home.tscn`。背景、透明小墨立绘、聊天 UI、飞花令 UI 各自独立。
- `ui/home/chat_ui.tscn`：纸签按钮、对白气泡、当前回复、输入框、发送、历史展开入口。位置、字体、文字与交互均可在 Godot 编辑器调整；聊天脚本不重排这些节点。
- `ui/home/feihualing_layer.tscn`：独立飞花令界面，默认隐藏，进入时隐藏聊天 UI，退出恢复。
- `scripts/home/home_chat.gd`：负责聊天请求、切换与信号。仅背景会随视口变化铺满窗口。
- 所有主界面动态文字共用 `ui/shared/comic_font.tres`，不烘焙进插画；字体使用系统楷体，缺失时按资源中的后备字体回退。

## 素材与生成记录

使用内置 ImageGen，参考已批准的 `art/concepts/home_ui_v1.png`，逐件生成；原素材保留。素材中没有功能文字或点击逻辑。

| 文件 | 要求 / 提示词要点 |
| --- | --- |
| `art/backgrounds/home_room_v2.png` | 保留暖阳木屋、山景与茶桌，去掉角色、剑及所有 UI，重建原遮挡处 |
| `art/character/sword_spirit_home_cutout_v1.png` | 单独提取小墨、服饰与剑，透明背景，保留姿势与面容 |
| `art/ui/home/menu_tag_v1.png` | 空白悬挂纸签，象牙白纸、青金配色、白花装饰与流苏，透明背景，无文字 |
| `art/ui/home/input_strip_v1.png` | 狭长空白纸质输入条，右侧青色发送区域，透明背景，无文字 |

输入条用 AtlasTexture 排除图像透明留白；它仍然是绘制素材，LineEdit 与 Button 是独立的原生控件。菜单悬停放大 4%，不透明度不变。

## 交互与验证

默认短对白；长回复可在小气泡内部滚动，完整记录通过“回看对话”展开，不截断原对话内容。聊天、特殊事件、远征、存档与飞花令沿用现有逻辑。缺失对话服务时飞花令仍可进入并退出，界面显示配置提示。

`tools/home_ui_smoke.gd` 在隔离存档、离线模式下检查背景铺满、历史展开收起、长文本保留、飞花令进入退出。加 `--home-screenshot` 用实际渲染器保存 `art/concepts/home_ui_implemented.png`。另运行 `tools/ui_structure_smoke.gd` 检查现有场景绑定与布局。

在线聊天与对诗需要本地服务配置，本轮未发出实际模型请求。测试不改玩家存档。

## 阅读体验调整
立绘缩小并露出完整发饰。对白关闭滚动条，按字体和文本区域拆段，点击继续；历史保留完整内容。历史改为独立纸页 art/ui/home/history_page_v1.png（内置 ImageGen：象牙白手绘纸、青金角饰、大面积空白、无文字无气泡尾、透明背景），标题和收起按钮仍是独立控件。聊天提示约束先接住玩家话语，不凭空编传闻、任务或身世；模型输出仍需实际游玩观察。
