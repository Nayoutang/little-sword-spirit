# 主界面接入

启动场景为 `scenes/main_menu.tscn`，美术沿用已确认的主界面效果图。底图保留标题、装饰与角色，菜单文字由原生 Button 绘制并响应鼠标和键盘。背景与按钮共用设计坐标，窗口变化时同步缩放。

- 开始游戏：自动使用第一个空存档，直接进入全新序章，完整重置角色与历练状态。已有存档不会覆盖；全部占满时进入清理页，删除仍需两次点击确认，再返回主界面开始。
- 继续旅途：进入已有存档选择，无存档时主界面入口禁用。
- 存档页新增返回主界面；家中存档入口仍显示所有存档。
- 存档由 3 个扩为 12 个，采用可滚动列表，键盘焦点自动跟随滚动；原有三个存档的路径与格式兼容。
- 设置：全屏切换（同 F11）与 Master 音量；设置由 WindowMode 保存至 user://display_settings.cfg，独立于剧情存档。
- 退出游戏：使用现有 RunState 的退出保存机制。

本次美术修改仅主界面和家中界面；其他剧情、战斗、卡牌图片未替换。

来源：内置 imagegen，`art/concepts/main_menu_sword_corrected_v1.png` 为确认效果图。主界面编辑仅移除四个菜单文字，保留标题、人物、古剑与布局；家中编辑使用加宽透明画布补全右轮廓，并以 `art/props/xiaomo_sword_sheathed_v1.png` 为剑形参考。未使用 CLI 图像生成。

验证：`tools/main_menu_smoke.gd` 覆盖新游戏、继续、存档保护、返回与音量；使用隔离 APPDATA。`tools/home_art_preview.gd` 可生成家中实际渲染截图。预览与补绘只操作素材文件，不触碰玩家存档。
