# 留盾敏感性：执行前登记

已完成，见 [结果](retain-shield-sensitivity-results-2026-10-06.md)。以下配置按执行前登记保留。

保留现有能力、增益、倍率和脚本，不削弱数值。种子400001–400020，每组20场，总80场，玩家90生命、敌人180生命、牌组15张。

- 间歇H30：留盾+A，一张/两张撞击（原位置替换平刺，少一张撞击即多一张平刺）。两张组重跑用于原档核验。
- 持续H24：敌人每回合单段攻击，分别无新牌+B、留盾两张撞击+A。留盾仍替换一张横架，固定立即启动；B按已展示攻击防御，因此每回合可防御。

持续H24是明确更高频率的压力对照，两回合原始伤害48，而间歇组30。不宣称预设入伤/新增盾比例等于1.67，需按这个防御牌组与实际小墨选择实测。没有弱敌（入伤明显少于盾）配置，不能据此排除更弱对手中的积累。

沿用预警：四个相邻完整两回合周期出现三次严格起始盾量增加，至少11/20场触发组级信号；撞击有效伤害达到60记高爆发。所有场次作分母，报告观察不足场次；持续组按固定两回合窗口记录起始盾相位，两回合都计入入伤。

比较胜负、死亡、截断、生命范围、实际观察及胜利回合、每场撞击数、有效伤害、扣盾前潜在峰值、增益分组、同相位起始盾曲线与来源。一张/两张改变出牌频率与卡位，而不改变伤害公式；峰值会随实际盾量和战斗长度变化，不预设一张组峰值必然更低。

实际压力口径：只用已执行敌方阶段，将执行攻击段伤害求和除以同阶段新增盾总和；完整两回合周期也另列比例，不能用新增盾阶段分子除以包含末次提前击杀的全场回合数。截断与死亡保留，仍不扩展200/1000对，不升级规划器。

若持续场景两组都频繁死亡，说明相对比较受高压限制，不因此直接认定组合过弱；若组合仍快且稳，也只能指出该对照下的表现，不作通用强度证明。
