# 第二轮护盾场景标定：只用脚本B

撤回要求无留盾A也能存活的门槛。无留盾A在蓄力回合打出的盾作废，结果只作说明。以后留盾+A对无留盾+B衡量合理玩法下的整体体验差异；跨脚本差值不是固定策略下单卡的因果效应。

沿用15张测试牌组、90生命、交心阶段、无额外领悟、脚本B与本地后备小墨。敌人蓄力/单段重击交替，仅改敌方生命与H；种子400001–400020。第一轮8配置160场，随后180生命/H30补20场，总180场，无新牌。伤害按实际扣敌生命计数，过量伤害不计。

每场三类来源合计等于敌方初始生命减最终生命，守恒检查通过。小墨在结束玩家回合时造成的直接伤害归小墨，玩家打出手牌或华彩时造成的伤害归对应动作；小墨提供的攻击加成仍计入这些玩家动作的伤害。因而“小墨直接伤害近零”不等于“小墨没有输出贡献”。本地后备策略在180/H30执行引势105次、拱卫97次、衔锋1次、守诺1次，主要通过增益和护盾参与。该分布不保证与正式LLM相同。

新护盾攻击贡献在同一归属规则下记录，但是否变强还需看华彩触发、替换掉的平刺伤害及整体存活，不以撞击伤害单项作为净收益。
