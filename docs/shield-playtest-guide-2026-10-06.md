# 护盾与弹反真人试玩

在项目目录执行 `./tools/play-shield.ps1`。默认沿用正式LLM配置；配置不可用时沿现有后备路径处理。若要明确使用本地后备，执行 `./tools/play-shield.ps1 -Offline`。入口不写正式存档，试验牌也未加入常规奖励池。

- 1：间歇单段，180生命，每两回合攻击30。
- 2：间歇三段，重击拆为10+10+10。
- 3：持续单段，每回合攻击24。
- 4：持续三段，每回合8+8+8。
- R：重开当前模式。数字键切换后立即重开。

玩家90生命、3精力、4张起手；交心阶段，无额外领悟。15张牌：留盾、回锋、横架×2、铁门闩×2、藏锋×2、撞击×2、平刺、叠浪、调息×2、掠影。当前入口是三组件组合体验，不是无新牌参照实验。

请2–3人各玩几局，重点记录：

1. 留盾启动与高盾撞击是否让人期待，80左右的蓄力伤害是否符合游戏想要的高光。
2. 持续攻击时能否主动放弃撞击，把精力用于防御；撞击是否频繁被视为废牌。
3. 弹反连击能否被感知；是否知道先用流光/华彩再打会清连击的防御牌，出牌顺序是否有趣。
4. 小墨是否常选守诺等格挡意向；不要把后备策略的引势节奏当作正式LLM必然行为。

完成战斗的摘要及意向记录写入 `.godot/shield-playtest.jsonl`，1MiB轮转，避免无限增长。不要在试玩后因为一场高伤害就调整数值，先记录玩家的选择与感受。

入口已通过离线无界面的启动检查；尚未完成真人试玩、图形界面的视觉验收或正式LLM连通性验收。数值诊断见[收尾报告](parry-and-long-results-2026-10-06.md)。
