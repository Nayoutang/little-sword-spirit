# 小墨古剑造型统一标准

本次仅应用于主界面与家中角色。用户已明确缩小范围，其他漫画、战斗立绘、卡牌不改。

确认素材为 `art/props/xiaomo_sword_sheathed_v1.png`，提取自用户认可的主界面效果图；它是唯一带鞘剑参考，不采用另行生成的出鞘剑设计。所有局部编辑应附此参考，不重新设计。

- 中国直身双刃剑，结构依次为剑首、深色短剑柄、简洁横护手、笔直细长剑身。握柄长度约为剑身的四分之一，禁止伞柄、长杖和复杂筒状结构。
- 出鞘时，银灰金属双刃和尖端必须可辨；入鞘时，深青色硬质剑鞘与剑柄沿同一直线连接，鞘口、护手、鞘尾明确，禁止出现第二把剑柄或重复护手。
- 金色装饰仅保留少量边饰；单束短青色剑穗系于剑首，不从鞘中间长出，不铺满桌面，不遮住结构。
- 闲坐场景完整带鞘古剑平放桌面，小墨手放桌上，不握住剑鞘。战斗握剑柄，手指与护手分离，不握刃或鞘身。
- 修图仅修改剑及必要的手部接触，保留人物身份、衣饰、构图、对白、分镜与界面。

主界面背景为 `art/backgrounds/main_menu_v1.png`。家中立绘为 `art/character/sword_spirit_home_cutout_v2.png`，补全右侧发丝、衣袖、裙摆与剑鞘，真实透明通道；保留 v1 原图。场景扩大显示区域，维持人物近景大小，修复原图右侧竖直裁切。
