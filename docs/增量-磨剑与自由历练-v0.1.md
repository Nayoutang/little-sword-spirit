# 增量：磨剑、自由历练内容、骰局→战斗、离线台词（2026-10-19）

纯增量，不改已有规则。数值首版，待试玩。

## 一、磨剑（卡牌升级）
- 升级后的牌 id = 原 id + 100（`CardDatabase.UPGRADE_OFFSET`），牌组、存档格式不变，旧档直接可读。
- 41 张可升级（心魔、流光、华彩除外）。每张只改数值，名字后加「+」，插画用原图。数值表：`card_database.gd` 的 `UPGRADES`。
  - 攻击多为伤害 +3～+6；防御格挡 +3；抽牌 +1；能力牌费用 -1。
- 在哪磨：
  - **宝箱**多了第五个选项「磨剑：升级一张牌」，点开后可以「先不磨」退回宝箱。
  - **路遇**新增「路边铁匠」「无字剑碑」两个能磨剑的事件。
- 能力牌磨过以后，奖励里不再出原版；拿到磨过的路线核心牌，同路线的牌照样更常出现。

## 二、自由历练内容
- **新敌人**（只在自由历练线外出现，已接入独立水墨立绘，资源见 art/enemies/free_play）：
  - 血衣刀客：每回合攻击 +2，越拖越疼。
  - 墨医：回春与普攻交替，回春给血最少的同伴回血。
- **新路遇 6 个**：路边铁匠、无字剑碑、迷路的孩子、茶摊说书、夜狼、落魄书生（共 15 个）。

## 三、大话骰 → 战斗
- 骰局里累计看穿她吹牛 5 次后解锁（`RunState.DICE_READ_AT`）；解锁那局她会说一句，并提示之后的变化。
- 解锁后的战斗：她每回合出完牌，会提前说出下回合想怎么配合（替你挡 / 把机会留给你 / 最后一剑给她），下回合多半照做（选牌打分 +18，战况紧急时仍可能改）。
- 说什么取决于这一趟的默契倾向；没有明显倾向时看战况（你残血→守护，连击高→收尾）。

## 四、离线台词
- 战斗出牌理由从每类 1～2 句扩到 3～4 句，按意向、关系深浅、这一趟的倾向分组；同一战况说同一句，战况一变就换。
- 回家时会就着这一趟说一句：她最常怎么配合你（挡 / 让 / 收尾），自由历练打赢首领时再说一句剑境的话。
