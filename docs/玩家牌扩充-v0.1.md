# 玩家牌扩充 v0.1（2026-10-15）

目的：玩家牌从「数值变体」变成有个性的构筑。一半新牌读小墨本回合亮出的意向，每条流派补一张能跨回合积累的引擎牌，再加几个新动作。新牌不改变小墨的决定，只读她的意向。

玩家牌 17 → 31 张（不含流光、华彩、心魔）；奖励池 14 → 26 张（第二章另加 2 张紫线牌）。

## 小墨意向的四类

由她亮出的牌决定（battle.gd `_companion_intent_kind`）：收尾（带「收尾」标签：独断、十步）＞ 让给你（援护立场：引势、拱卫、同心剑鸣、磨剑、断水、长风）＞ 守护（带「守护」标签：剑影回护、守诺、回护、霜寒、阴山）＞ 攻击（其余造成伤害的）。她被紫线缠住时没有意向。

## 规则补充

- **稀有度**：奖励三选一按 普通 6 : 罕见 3 : 稀有 1 加权、不重复。旧牌稀有度：行云、留盾为稀有；破锋、藏锋、追风、护盾攻击、回锋为罕见；其余普通。
- **能力牌**：所有能力牌同名不叠加，已在牌组里就不再出现在奖励中（原来只限行云、留盾）。
- **本场移除**：带此规则的牌打出后不进弃牌堆，下一场战斗照常在牌组里。
- **她的加伤 / 加盾**：开路、并肩给的只作用于她本回合这一次出手，没用上就作废；听风给的存着，直到她下次造成伤害。
- **插画**：新牌先借同类旧牌的图（card_art_catalog.gd `PLACEHOLDER_FILES`），出图后加进 `PLAYER_FILES` 即可替换。

## 文件

card_database.gd（定义、稀有度、加权抽取）、combat_types.gd（编号）、player_effect_resolver.gd（读意向、条件加成）、battle.gd（意向类别、新效果、引擎钩子、本场移除）、card_presentation.gd / card_art_catalog.gd（牌面）、battle_reward.gd / event.gd（加权奖励）、card_library.gd（图鉴显示稀有度）。回归：tools/new_cards_smoke.gd。
