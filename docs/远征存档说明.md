# 远征存档

远征会在约定、地图、战斗开场、事件和奖励等节点自动保存。各界面提供“保存并退出”，存档选择界面可继续当前远征。

保存内容包括地图种子与已走路线、生命与生命上限、当前牌组、约定、奇遇记录及待领取奖励。战斗中退出后从该场战斗开场重来，敌人与抽牌顺序保持一致；小墨的在线决策重新生成。飞花令尚未结算时从选择令字重新开始，已经获得的剑技或结算结果会保留。

奖励选项固定，精英选牌后的删牌步骤单独保存，结算不会重复发放奖励。进入结局剧情时结束普通远征存档；结局战斗也可从开场恢复。

存档沿用各槽位文件，远征数据版本为 1。写入使用临时文件与备份；主文件损坏可读取备份。未知版本或无效远征数据不会部分恢复。旧版关系存档仍可读取。保存失败时保留当前界面，允许重试。
